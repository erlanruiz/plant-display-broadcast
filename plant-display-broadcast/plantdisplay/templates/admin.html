Samsung / smart TVs

No TVs yet — scan, or open the viewer URL on the TV and it will appear after it connects.
⏻ On uses Wake-on-LAN — enable Power On with Mobile / IP Remote on the TV (Settings → General → Network → Expert Settings). Off and Open viewer use Samsung's remote API — the first command shows an Allow Plant Display? popup on the TV; accept it once. Open viewer launches the TV browser already logged in, playing its assigned source at . Tip for stubborn TVs: open the TV browser once, go to the viewer URL, log in, and set it as the browser's home page (browser menu) — then any browser launch lands on Plant Display automatically, even when the firmware ignores the passed URL.
